# DisasterOps AI - Architecture

## Core Modules

1. Citizen Portal
   - Register/Login
   - Submit SOS
   - Track Request Status
   - View Nearby Shelters

2. Admin Command Center
   - Emergency Queue
   - Team Management
   - Resource Management
   - Mission Tracking
   - Analytics Dashboard

3. AI Priority Engine
   - Priority Classification
   - Confidence Score
   - Prediction Explanation

4. Rescue Team Matching Engine
   - Availability Check
   - Distance Calculation
   - Specialization Matching
   - Equipment Matching

5. Resource Allocation Engine
   - Resource Recommendation
   - Availability Validation

6. Shelter Module
   - Shelter Management
   - Capacity Tracking

7. SMS Fallback Module
   - SMS Parser
   - SOS Creation from SMS

8. Reporting Module
   - Mission Reports
   - Analytics

9. Database Layer
   - MySQL Storage

10. GIS Layer
   - Leaflet Maps
   - OpenStreetMap
